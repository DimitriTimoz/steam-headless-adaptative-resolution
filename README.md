# Steam Headless Resolution Fix

Dynamic resolution switching for `docker-steam-headless` + Sunshine + Moonlight.

This project applies a small overlay on top of the official `docker-steam-headless` container so the virtual X11 display follows the resolution requested by Moonlight.

Useful when switching between clients with different resolutions or aspect ratios, such as:

- 2560x1080
- 2560x1600
- 1920x1200
- 1920x1080
- Steam Deck / tablets / laptops

## Docker Compose override

This project patches the existing Sunshine config generated by `docker-steam-headless`.

```yaml
services:
  steam-headless:
    volumes:
      - ./scripts/res-switch:/home/default/bin/res-switch:ro
      - ./scripts/res-reset:/home/default/bin/res-reset:ro
      - ./install/99-install-res-switch.sh:/opt/res-switch/99-install-res-switch.sh:ro
```

## Install

Run from the same directory as your `docker-compose.yml`:

```bash
chmod +x install.sh
./install.sh
```

The installer will:

* start the container;
* patch `/home/default/.config/sunshine/apps.json`;
* restart Sunshine.

## Check installation

```bash
docker compose exec steam-headless cat /home/default/.cache/log/res-switch-install.log
```

Expected:

```text
[res-switch] Installing Sunshine resolution switch hook...
[res-switch] apps.json patched successfully
[res-switch] Done.
```

## Moonlight settings

Make sure Moonlight requests the resolution you want.

For example:

```text
2560x1080
2560x1600
1920x1200
1920x1080
```

Avoid generic modes like `Auto`, `Native`, or `1080p` if they do not map correctly to your display.

## Uninstall

```bash
./uninstall.sh
```

This removes the hook from Sunshine and restores the previous config if a backup exists.

## Troubleshooting

### Moonlight error 503

Check that services are running:

```bash
docker compose exec steam-headless supervisorctl status
```

You want `xorg`, `desktop`, and `sunshine` to be `RUNNING`.

### The resolution has not changed after changing Moonlight resolution
This can happen if the latest mooonlight connection is still active. Try disconnecting and reconnecting Moonlight.
